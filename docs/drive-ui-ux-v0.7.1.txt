CloudSaver v0.7.1 UI/UX Design System & Specification
This document provides the exhaustive Design System, Visual Foundations, Component Specifications, and Implementation Blueprints for CloudSaver v0.7.1, an enterprise FinOps management platform.


________________


1. Executive Summary & Design Principles
CloudSaver v0.7.1 transforms enterprise cloud cost visibility into automated, actionable remediation. The redesign eliminates visual clutter, reduces cognitive load, and standardizes multi-cloud governance (AWS, Azure, GCP) into a cohesive interface.
Core Design Principles
* Context over Density: Surface actionable savings opportunities without hiding telemetry. Deep technical data is accessible through progressive disclosure (slide-over drawers and modal layers).
* Zero-Ambiguity Statuses: Every recommendation explicitly states its state, impact, risk tier, and provider provenance using unified color ramps and badge architecture.
* Keyboard-First Workflows: Power users can navigate, filter, select, and remediate findings via global shortcuts and an integrated Command Palette (Cmd+K).
* Deterministic Safety: Destructive actions or multi-cloud automated script applications require explicit confirmations, dry-run validations, and explicit visual warnings.

3. Modernized Information Architecture & Navigation
The layout follows a durable shell architecture designed for fast navigation across enterprise scopes.
Layout Blueprint
* Left Navigation (Sidebar): Collapsible panel (240px expanded, 64px collapsed). Contains high-level functional areas:
   * Executive Dashboard (Overview, Spend Velocity, Unit Economics)
   * Inventory & Findings (Data Grid, Resource Graph, Idle Assets)
   * Automation Engine (Policies, Remediation Pipelines, Execution Logs)
   * Cost Allocation (Tag Governance, Chargeback, Showback)
   * Settings & Integrations (Cloud Accounts, IAM, Webhooks, ITSM Connectors)
* Top Bar (Command & Workspace Header):
   * Workspace Switcher: Quick-switch dropdown (e.g., Production Multi-Cloud, Staging-AWS, FinOps-Sandbox).
   * Global Command Trigger: Cmd + K search input triggering quick actions and resource lookup.
   * Tenant / Scope Picker: Multi-account selector with direct filter bindings.
   * Notification Bell & User Profile: Drawer trigger for system alerts and user preference toggles.

4. Advanced Data Grid & Inventory UX
The core interface of CloudSaver v0.7.1 is built on a custom data grid powered by TanStack Table v8.
Data Grid Features
1. Multi-Dimensional Filtering System:
   * Combinatorial filters for Cloud Provider (AWS, Azure, GCP), Resource Type (EC2, RDS, Blob Storage, K8s Pod), Risk Score (Low, Medium, High, Critical), and Tag key-value pairs.
   * Filter chips display active state with quick dismiss buttons (×).
2. Bulk Action Floating Toolbar:
   * Appears fixed at the bottom-center of the screen when one or more rows are selected.
   * Actions include: Bulk Remediation, Export CSV/JSON, Assign to Jira, and Suppress Finding.
3. Column Customization & Density Switcher:
   * Popover control allowing reordering, pinning (left/right), and toggling visibility of table columns.
   * Density toggles: Compact (28px row height), Medium (36px row height), and Relaxed (48px row height).

Drawer Tab Architecture
Tab 1: Evidence & Telemetry
* Metric Graphs: 14-day continuous telemetry for CPU Utilization (< 1% average), Disk I/O Ops (0 IOPS), and Network Throughput (< 10 KB/s total).
* Metadata List: Volume ID, Creation Date, Last Attached EC2 Instance ID, Attachment State (detached), Encryption Status (KMS Encrypted).
Tab 2: Cost & Waste Breakdown
* Historical Spend: 90-day accumulated cost chart showing zero utilization cost leakage ($14.00/day).
* Projected Annual Savings: $5,040.00/yr if deleted or snapshots created and original volume purged.
* Risk-Adjusted Savings: Calculation incorporating snapshot retention overhead.
Tab 3: IaC & Automation Snippets
* Terraform (HCL) Import / Remediation:


# Automated remediation resource modification


resource "aws_ebs_volume" "remediated_volume" {


  availability_zone = "us-east-1a"


  size              = 3000


  type              = "gp3"

    Environment = "production"


    ManagedBy   = "CloudSaver-v0.7.1"


    AutoCleanup = "true"


  }


}

* Jira / ServiceNow Integration panel:
   * Linked Issue: FIN-4819 (Status: In Review, Assignee: Person)
   * Audit Log: Timestamped record of scan identification, notification delivery, and auto-remediation schedule windows.

Next.js 15 Data Grid & Slide-Over Implementation Specification
The following React component snippet outlines the TanStack Table v8 integration with dynamic row selection, density states, and custom slide-over drawer triggers using Radix UI primitives, Lucide icons, and Sonner toast alerts."use client";


import * as React from "react";


import {


  useReactTable,


  getCoreRowModel,


  getFilteredRowModel,


  getPaginationRowModel,


  getSortedRowModel,


  flexRender,


  ColumnDef,


  RowSelectionState,


} from "@tanstack/react-table";


import { Check, ChevronRight, ShieldAlert, SlidersHorizontal, Trash2 } from "lucide-react";


import { toast } from "sonner";


import { Finding } from "@/types/inventory";


interface DataGridProps {


  columns: ColumnDef<Finding>[];


  data: Finding[];


  onOpenDetailDrawer: (findingId: string) => void;


}


export function FindingsDataGrid({ columns, data, onOpenDetailDrawer }: DataGridProps) {


  const [rowSelection, setRowSelection] = React.useState<RowSelectionState>({});


  const [density, setDensity] = React.useState<"compact" | "medium" | "relaxed">("medium");


  const table = useReactTable({


    data,


    columns,


    state: { rowSelection },


    onRowSelectionChange: setRowSelection,


    getCoreRowModel: getCoreRowModel(),


    getFilteredRowModel: getFilteredRowModel(),


    getPaginationRowModel: getPaginationRowModel(),


    getSortedRowModel: getSortedRowModel(),


  });


  const selectedRowCount = Object.keys(rowSelection).length;


  const handleBulkRemediate = () => {


    toast.success(`Initiated remediation for ${selectedRowCount} resource(s)`, {


      description: "Progress can be tracked in the Automation Log tab.",


    });


    setRowSelection({});


  };


  const densityPaddingMap = {


    compact: "py-1 px-2 text-xs",


    medium: "py-2.5 px-3 text-xs",


    relaxed: "py-4 px-4 text-sm",


  };


  return (


    <div className="w-full space-y-4">


      {/* Grid Toolbar & Controls */}


      <div className="flex items-center justify-between border-b border-slate-200 pb-3">


        <div className="flex items-center gap-2">


          <span className="text-sm font-semibold text-slate-900">Findings</span>


          <span className="rounded-full bg-slate-100 px-2 py-0.5 text-xs text-slate-600">


            {data.length} Total


          </span>


        </div>


        


        <div className="flex items-center gap-3">


          <div className="flex items-center rounded-md border border-slate-200 bg-white p-1">


            <button


              onClick={() => setDensity("compact")}


              className={`px-2 py-1 text-xs rounded ${density === "compact" ? "bg-slate-100 font-medium text-slate-900" : "text-slate-500"}`}


            >


              Compact


            </button>


            <button


              onClick={() => setDensity("medium")}


              className={`px-2 py-1 text-xs rounded ${density === "medium" ? "bg-slate-100 font-medium text-slate-900" : "text-slate-500"}`}


            >


              Medium


            </button>


            <button


              onClick={() => setDensity("relaxed")}


              className={`px-2 py-1 text-xs rounded ${density === "relaxed" ? "bg-slate-100 font-medium text-slate-900" : "text-slate-500"}`}


            >


              Relaxed


            </button>


          </div>


        </div>


      </div>


      {/* Main Table Container */}


      <div className="relative overflow-x-auto rounded-lg border border-slate-200 bg-white shadow-sm">


        <table className="w-full text-left border-collapse">


          <thead>


            {table.getHeaderGroups().map((headerGroup) => (


              <tr key={headerGroup.id} className="border-b border-slate-200 bg-slate-50/75">


                {headerGroup.headers.map((header) => (


                  <th key={header.id} className="px-3 py-2 text-xs font-semibold text-slate-600">


                    {flexRender(header.column.columnDef.header, header.getContext())}


                  </th>


                ))}


              </tr>


            ))}


          </thead>


          <tbody className="divide-y divide-slate-100">


            {table.getRowModel().rows.map((row) => (


              <tr


                key={row.id}


                onClick={() => onOpenDetailDrawer(row.original.id)}


                className="cursor-pointer transition-colors hover:bg-slate-50/80 group"


              >


                {row.getVisibleCells().map((cell) => (


                  <td key={cell.id} className={`${densityPaddingMap[density]} text-slate-700`}>


                    {flexRender(cell.column.columnDef.cell, cell.getContext())}


                  </td>


                ))}


              </tr>


            ))}


          </tbody>


        </table>


      </div>


      {/* Floating Bulk Action Bar */}


      {selectedRowCount > 0 && (


        <div className="fixed bottom-6 left-1/2 -translate-x-1/2 flex items-center gap-4 rounded-xl bg-slate-900 px-5 py-3 text-white shadow-2xl z-50 border border-slate-800 animate-in fade-in slide-in-from-bottom-4">


          <span className="text-xs font-medium text-slate-300">


            <span className="font-bold text-white">{selectedRowCount}</span> resource(s) selected


          </span>


          <div className="h-4 w-px bg-slate-700" />


          <button


            onClick={handleBulkRemediate}


            className="flex items-center gap-1.5 rounded-md bg-indigo-600 px-3 py-1.5 text-xs font-semibold text-white hover:bg-indigo-500 transition-colors"


          >


            <ShieldAlert className="h-3.5 w-3.5" />


            Remediate Selected


          </button>


          <button


            onClick={() => setRowSelection({})}


            className="text-xs text-slate-400 hover:text-white transition-colors"


          >


            Clear Selection


          </button>


        </div>


      )}


    </div>


  );


}
